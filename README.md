## 🚀 About

I take code from a commit to a reachable, observable production system: pipelines, containers, clusters, cloud infrastructure, and the debugging that starts when a green pipeline still isn't reachable.

```bash
$ git push            # pipeline builds, scans, deploys
$ kubectl get pods    # verify the rollout
$ docker scout cves   # scan before shipping
```
